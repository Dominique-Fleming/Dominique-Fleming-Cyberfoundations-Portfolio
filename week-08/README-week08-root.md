# CyberFoundations — Week 8 Labs

## Module 3: Practical Cryptography — Protecting the Data

Complete the five required labs in order:

1. **Protect the Incident File** — encrypt, decrypt, and prove an exact match.
2. **Detect the Change** — compare SHA-256 digests.
3. **Meet Your Key Pair** — create a dedicated SSH key pair.
4. **Prove Who Signed It** — sign, verify, change, and verify failure.
5. **Log In with a Key** — prove public-key-only SSH authentication.

## Required Order

Labs 1–4 use the prepared Week 8 workspace. Lab 5 depends on the SSH key created in Lab 3. Do not skip Lab 3.

## Starting Location

Use your assigned `cf-student-XX` VM as the `analyst` user. At the start of each lab, run the exact pre-lab check shown in that worksheet.

## Non-Negotiable Safety

- Never submit a private key, `.pem` file, password, or passphrase.
- Never display a private key in the terminal.
- Do not use `sudo`, install packages, or change Azure/SSH server settings.
- Submit only the completed Markdown worksheet and the specifically named screenshots.
- Keep student-created cryptographic files on the VM for Week 9.

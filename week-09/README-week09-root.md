# CyberFoundations — Week 9 Labs

## Module 3: Digital Trust — Certificates and TLS

This file is the **overview for the whole `week-09` folder**. It sits directly inside `week-09/`. It is different from `week-09/labs/README-week09-submissions.md`, which is the detailed evidence and submission guide inside the `labs` folder.

Complete the two required labs in order:

1. **Investigate a Certificate** — read a real website's certificate: name, dates, issuer, and chain.
2. **Build and Test Digital Trust** — create a key and request, issue and inspect a certificate, then test a loopback-only TLS connection that passes and deliberately fails.

## Required Order

Lab 01 is a read-only browser investigation and builds the vocabulary used in Lab 02. Do not skip it. Lab 02 depends on the Week 8 workspace and your existing SSH setup, so keep that work in place.

## Starting Location

Use your assigned `cf-student-XX` VM as the `analyst` user. At the start of each lab, run the exact pre-lab check shown in that worksheet.

## Non-Negotiable Safety

- Follow the Vault Exchange Trust and Key Safety Rule in both worksheets.
- Never submit a private key, `.key.pem` file, password, or passphrase.
- Do not add the practice issuing office to your computer or browser's accepted list.
- The TLS listener stays on `127.0.0.1:8443` and is stopped when you finish.
- Do not use `sudo`, install packages, or change Azure settings.
- Upload only the named worksheets and reviewed screenshots — never `git add .` from the practice folder.

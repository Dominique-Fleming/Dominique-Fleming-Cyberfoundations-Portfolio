# CyberFoundations Week 6 — Cloud Heights

**Module 2 — Networking & Cloud Foundations**

Week 5 taught how a connection reaches a machine. Week 6 moves into a live Azure environment: students enter their assigned Cloud Heights VM through the Lab Portal and Azure Bastion, practice SSH authentication, apply the Week 5 network toolkit to real cloud behavior, read the private VNet/subnet design, and organize the week's failures with OSI/TCP-IP layers.

## Week 6 Labs

1. **Lab 01 — Claiming Your Room in Cloud Heights** — first live Bastion session; `hostname`, `whoami`, `pwd`; snapshots and least privilege.
2. **Lab 02 — Knocking on Door 22** — manual SSH, host fingerprint, password authentication, reachability vs authentication.
3. **Lab 03 — The Grid, For Real** — live `ip addr`/`ip route`, Azure's silent gateway, DNS, Grid Beacon.
4. **Lab 04 — Reading the Blueprints** — VNet/subnet/private IP/NAT/Bastion verification.
5. **Lab 05 — Layer Detective** — OSI/TCP-IP case reasoning.
6. **Lab 06 — Night Watch (optional stretch)** — home-network comparison and redaction.
